## 올리는 법 (GitHub Pages)

1. GitHub 에서 새 저장소(repository)를 만듭니다. **Public** 으로 만들어야 무료로 됩니다.
2. 이 폴더의 파일을 저장소에 올립니다 (웹에서 **Add file → Upload files** 로 끌어다 놓으면 됩니다).
3. 저장소 **Settings → Pages** 로 갑니다.
4. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/ (root)` 로 두고 저장합니다.
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 열립니다.

다음부터 고칠 때는 `index.html` 하나만 새로 올리면 **모든 선생님·학생 화면이 같이 바뀝니다.**

> `.nojekyll` 파일은 지우지 마세요. GitHub Pages 가 파일을 제멋대로 가공하지 않게 막는 표시입니다.

## 자동 반영 (작업 브랜치 → main → 사이트)

`main` 이 아닌 **아무 브랜치에 올려도 자동으로 `main` 에 합쳐지고**, 1~2분 뒤 사이트에 나타납니다.
`.github/workflows/deploy.yml` 이 그 일을 합니다.

이 저장소는 **이미 켜져 있어 그대로 동작합니다**(2026-09-02 첫 실행 성공 확인).
혹시 나중에 자동 반영이 갑자기 안 되면 여기를 먼저 보세요 —
저장소 **Settings → Actions → General → Workflow permissions** 가
**`Read and write permissions`** 여야 합니다.
(이 권한이 없으면 자동 반영이 거부되어 **Actions** 탭에 빨간 X 로 남습니다. 사이트는 그대로 유지됩니다.)

**잘 됐는지 보는 곳**: 저장소 위쪽 **Actions** 탭.
- 초록 체크 ✓ — main 까지 반영됐습니다. 잠시 뒤 사이트가 바뀝니다.
- 빨간 X — 반영되지 않았습니다. 사이트는 **이전 상태 그대로** 남습니다. 눌러서 이유를 봅니다.
  대부분 위의 권한 설정이거나, `main` 을 따로 고쳐서 생긴 충돌입니다.

**직접 올리고 싶을 때**: `main` 에 바로 올리면 됩니다. 그때는 이 자동 반영이 돌지 않고
Pages 가 곧바로 배포합니다.

**잠시 끄고 싶을 때**: Actions 탭 → 왼쪽 `main 에 자동 반영` → 오른쪽 `···` → `Disable workflow`.

> 이 자동 반영은 **올린 내용을 검사하지 않고 그대로 사이트에 내보냅니다.**
> 올리기 전에 확인하고 싶으면, 브랜치 주소로 먼저 열어 볼 수 있습니다:
> `https://raw.githack.com/<아이디>/<저장소>/<브랜치이름>/index.html`
